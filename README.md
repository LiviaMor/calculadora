# 🧮 Calculadora em Java com JUnit5

Projeto apresentado a disciplina de Projeto Integrador IV - A da PUC-GO. Este projeto foi desenvolvido para testes de funcionalidades de uma calculadora usando **JUnit5**, garantindo qualidade e precisão dos cálculos.  

## 📌 Sobre o Projeto
Este projeto implementa uma calculadora simples utilizando **Java** e valida suas operações por meio de **Testes Unitários** usando **JUnit5**.  

## ✨ Funcionalidades
- Operações matemáticas básicas (`+`, `-`, `*`, `/`).
- Tratamento de exceções, como divisão por zero.
- Testes unitários para cada operação, garantindo confiabilidade do código.

## 🛠️ Tecnologias Utilizadas
- **Java** (JDK 21)
- **JUnit5** (Testes unitários)
- **Maven** (Gerenciamento de dependências)
- **IDE** (IntelliJ IDEA)

## 📂 Estrutura do Projeto
```
calculadora/
│── src/
│   ├── main/java/scarlet
│   │   ├── Calculadora.java  # Implementação da calculadora
│   │   ├── Main.java    # Enum com tipos de operações
│   ├── test/java
│   │   ├── CalculadoraTeste.java  # Testes unitários com JUnit5
│   │   ├── CalculadoraTesteAvancado.java 
│── pom.xml  # Dependências do projeto
```

## 🔗 Como Usar
1. **Clone este repositório**  
   ```bash
   git clone https://github.com/LiviaMor/calculadora.git
   ```
2. **Abra o projeto na sua IDE**
3. **Compile e execute os testes**  
   ```bash
   mvn test
   ```
4. **Verifique os resultados** no terminal.

## ⚠️ Problemas Conhecidos
- Certifique-se de ter **JUnit5** configurado no seu projeto.
- O **Maven** deve estar instalado corretamente para rodar os testes.
